## Architecture Approach

```
Client Layer       →   React / Next.js
API Layer          →   Node.js / Express.js
Business Logic     →   Services / Controllers
ORM Layer          →   Prisma ORM
Database           →   MySQL
Security           →   JWT + RBAC + Middleware
```

✔ Clean folder structure — separation of concerns at every layer  
✔ RESTful API design with structured error handling  
✔ Secure authentication with role-based access control  
✔ Optimized queries and schema design for real-world load
